# Regras de apuração

## Prefeito (majoritário) - MVP
- Votos válidos = votos nominais (+ legenda, se aplicável conforme o manual)
- Brancos e nulos não entram no percentual
- Vencedor: mais votos; empate deve ser sinalizado, não resolvido
- Primeiro turno: vitória exige mais de 50% dos votos válidos (conferir a legislação vigente)
